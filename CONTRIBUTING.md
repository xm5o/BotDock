# Contributing

Thanks for helping BotDock.

## Before you start

- Keep changes focused.
- Use clear names.
- Do not add analytics or tracking.
- Do not log `.env` values or bot tokens.
- Test Windows behavior when you change process control code.

## Local setup

```bash
npm install
npm start
```

## Pull requests

Explain:

1. What changed.
2. Why it changed.
3. How you tested it.

Small pull requests are easier to review.
